保留：双卡 SIM 卡信息（SIM 1/2、订阅 ID、运营商）、当前默认上网卡、5G/4G 优先状态、自动切换策略、立即同步、刷新、停用策略、恢复原始模式、Root 重启电话服务、LSPosed 作用域 `com.android.phone`。

使用 `.github/workflows/build-apk.yml` 在原有仓库编译 APK，不需要新建仓库。

**验证范围：** 已检查源码引用与 ZIP 完整性。未在 Android SDK 环境中执行完整 Gradle 构建，也未真机验证。


## v0.6.1 自动策略纠偏

- `com.android.phone` 内启动后重试（开机 SIM / 默认数据订阅未就绪时重试）。
- 监听默认数据卡和 SIM 状态广播，并每 20 秒进行一次只读比对；仅发生偏差才写 USER 网络模式掩码。
- 默认数据订阅强制允许 NR，其他活动 SIM 强制清除 NR；保留其他网络制式位。
- 每次写入后立即读取校验；失败会报告错误并重试。
- 切换途中发现默认数据订阅变化则重新校验。
- 保留原有停用/恢复原始模式语义；停用后守护检查不会修改网络模式。
- 只保证 USER allowed-network-types 的 NR 位；ROM/运营商/硬件限制仍可能使实际网络停留在 LTE，不保证物理连接一定是 5G。
- 更改电话进程 Hook 后需要重启 `com.android.phone` 或整机，确保新代码加载。
