# 网络切换控制台 v0.5.1（QCI/5QI 按需检测测试版）

基于 v0.5.0；保留图标、应用名、LSPosed 推荐作用域 `com.android.phone`、5G/4G 自动切换和 SIM 网络概览。

## 新增
- 网络概览中每个已插卡槽分别展示 QCI/5QI。
- 单独的「读取 QCI / 5QI（实验性）」按钮：手动触发才检查当前数据承载；有点击反馈和 5 秒冷却。
- 通过电话进程内部的现有 QoS 对象尝试读取 `EpsQos.getQci()` 或 `NrQos.get5Qi()`。采用容量 1 的后台线程，不进入原来每 4 秒状态读取、双卡切换主链路；超时 2 秒并忽略迟到结果。
- 未拿到 QoS 时显示「未上报」「接口未提供」或异常类型。双卡独立读取；非上网卡没有活跃数据承载时通常不返回 QCI。

## 限制
这是实验性能力，不保证 ColorOS 16 提供内部接口；读到的默认承载 QCI/5QI 也不等于套餐优先级。**上下行签约速率继续显示 —**，不使用网络估算值伪装。

## 风险与验证
此功能有过旧版本造成电话进程不稳定的历史；本次降低调用频率并隔离线程，但不能保证厂商反射调用绝对安全。仅在手动点击时执行。请保留 v0.5.0 备份。首次安装要重新加载 `com.android.phone` 的 LSPosed Hook。

源码已静态检查、ZIP 完整性测试；未在安卓设备完成构建和真机验证。
