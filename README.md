# 网络切换控制台 v0.6.0 · 精简版（基于 v0.5.9）

保留：双卡 SIM 卡信息（SIM 1/2、订阅 ID、运营商）、当前默认上网卡、5G/4G 优先状态、自动切换策略、立即同步、刷新、停用策略、恢复原始模式、Root 重启电话服务、LSPosed 作用域 `com.android.phone`。

删除：QCI/5QI 及上下行 QoS 速率、数据和语音网络状态、连接频段和 ARFCN、DMS 硬件频段、NAS 频段偏好、NAS RF 当前射频状态、Root QoS 诊断模块。不会再执行这些自动探测任务，也不再编译相关 NDK 探针。

使用 `.github/workflows/build-apk.yml` 在原有仓库编译 APK，不需要新建仓库。

**验证范围：** 已检查源码引用与 ZIP 完整性。未在 Android SDK 环境中执行完整 Gradle 构建，也未真机验证。


## v0.6.1 自动策略纠偏

- `com.android.phone` 内启动后重试（开机 SIM / 默认数据订阅未就绪时重试）。
- 监听默认数据卡和 SIM 状态广播，并每 20 秒进行一次只读比对；仅发生偏差才写 USER 网络模式掩码。
- 默认数据订阅强制允许 NR，其他活动 SIM 强制清除 NR；保留其他网络制式位。
- 每次写入后立即读取校验；失败会报告错误并重试。
- 切换途中发现默认数据订阅变化则重新校验。
- 保留原有停用/恢复原始模式语义；停用后守护检查不会修改网络模式。
- 只保证 USER allowed-network-types 的 NR 位；ROM/运营商/硬件限制仍可能使实际网络停留在 LTE，不保证物理连接一定是 5G。
- 更改电话进程 Hook 后需要重启 `com.android.phone` 或整机，确保新代码加载。


## v0.6.2 稳定性优化

- 60 秒低频兜底检查、广播防抖，避免每 20 秒唤醒。
- 单 HandlerThread 串行执行；每次写入前检查最新默认数据订阅，发生切换就取消当前旧策略并重新调度。
- 先保障上网卡 NR 允许，再限制副卡 NR；仅修改 USER 掩码的 NR 位。
- 写入后即时读回 NR 位，并在有修改时延迟 1.8 秒再核验异步回写。
- SIM 或电话服务尚未就绪以及写入失败使用 2/5/10/30/60 秒指数退避，调度时避免叠加任务。
- 原始模式按卡槽 + cardId + subId 备份，首次写入前同步持久化，避免新 SIM 复用旧卡备份。
- 停用策略时取消待执行重试；恢复仅作用于仍匹配身份的 SIM。
- 保留 v0.6.0 精简界面，无新增频段 / QoS 功能。

限制：验证的是 USER 原因下允许的 NR 位，不代表 ROM/CARRIER 其他原因也允许 NR，更不能保证当前实际连接 5G。
